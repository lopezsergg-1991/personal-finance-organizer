# Environment Setup Requirements

## Purpose

This document tracks all tools, dependencies, and prerequisites required to build and run the Personal Finance Organizer project.

Whenever a new dependency is discovered, this document and the setup scripts must be updated.

---

# Required Dependencies

## Homebrew

Purpose:

Package manager used to install project dependencies on macOS.

Installed By:

setup-mac.sh

---

## Git

Purpose:

Version control and repository management.

Installed By:

setup-mac.sh

---

## Node.js

Purpose:

Frontend development environment.

Used for:

- React
- TypeScript
- Development tooling
- Package management

Installed By:

setup-mac.sh

---

## npm

Purpose:

Dependency management.

Provided by:

Node.js installation.

---

## npx

Purpose:

Run project tooling and application generators.

Provided by:

Node.js installation.
